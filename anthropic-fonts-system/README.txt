Anthropic website fonts — system-installable TrueType files

Family names inside the fonts:
- Anthropic Sans (regular and italic; variable weights)
- Anthropic Serif (regular and italic; variable weights)
- Anthropic Mono (regular and italic; variable weights)
- JetBrains Mono (regular)

The Anthropic fonts were converted from the WOFF2 files referenced by Anthropic's public website stylesheet. Their internal family, style, full, and PostScript names were normalized to remove the web-specific naming.

On Windows, select the TTF files, right-click, and choose Install. Restart apps that were already open.
